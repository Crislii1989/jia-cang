  • ④ 概览四卡改「竖排高卡」：卡内三段式——线性图标（25pt）→ 数字 + 单位（20pt/800，「件」11pt）→ 标签（10.5pt）；卡底是各不相同的水彩渐变底（粉/绿/蓝/紫），数字与图标同色系深色。四色顺序沿用参考图：物品总数=粉红、即将到期=绿、出借中=蓝、长期闲置=紫。其中「长期闲置」口径 = 超过 N 天（默认 90，设置内可调）未查看 / 未编辑的物品数。
  • ⑤ 分类改一行 4 个大圆：直径 56 的 pastel 渐变大圆（粉/蓝/绿/紫轮转）+ 11pt 标签；不再铺 2 行 8 个，超出部分收进「全部 ›」（分类名取实际数据，如「餐厨用品」）。
  • ⑥ 提醒改「卡组」：三行合并在一个白色圆角卡里，行间 1px 浅分割线；每行 = pastel 圆形缩略图（38pt）+ 名称（13pt/700）+ 彩色状态小字（逾期红 / 临期桃 / 闲置灰）；去掉「去处理」按钮，整行可点进详情。右侧灰色辅助位规范化为具体日期——左侧写状态+天数、右侧写日期（09-14 到期 / 06-01 登记），互不重复；无提醒时显示「一切妥当 ✅」空态。
  • ⑦ 底部导航 = 悬浮白色圆角条（V2.5，按参考图逐像素实测）：不再是满宽贴底的白条——高 60、圆角 20、底部内缩 8、带柔和投影（0 6px 16px rgba(150,90,70,.14)）。宽度比上方内容卡每侧宽出 6px（内容卡距屏幕边 14 / 条距 8），让条像托盘一样「托住」卡片，而不是被卡片挤窄。条底是半透明白 rgba(255,255,255,.86)，透出全局背景，不用毛玻璃、无模糊层；既没有顶部分割线，也没有激活态顶部指示线。4 个 Tab 均分栏宽（首页 / 物品库 / 收纳 / 我的）——点击态＝实心图标 + 珊瑚粉文字 #E8807F，未点击＝线性描边图标 + 暖棕文字 #9A7C5C。中央珊瑚圆钮 40px（#F79C84、白色「+」）落在条内偏上（距条顶约 3px），不探出条外。滚动到底的收尾：内容区自带 12px 底部留白，最后一张卡与导航条之间始终留出呼吸位，不会贴在一起。注意导航条在滚动区之外（是机型列的独立子项），内容永远不会被压在条下；顶部导航（标题 / 操作）本就没有底板，保持透明。详情页与添加页底部的操作条（V2.6）已并到同一套悬浮语言——同样是悬浮圆角白条、同内缩 / 高 60 / 圆角 20 / 同一投影、同样去掉顶部分割线；唯一差别是底色比导航条略实（.92 vs .86），因为它托的是按钮，要保证按钮对比度。详情页的删除旋钮仍独立于操作条、浮在其左上方并贴左边（不可拖动），随操作条一起上移。
