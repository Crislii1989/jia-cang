  • ⑥ 提醒改「卡组」：三行合并在一个白色圆角卡里，行间 1px 浅分割线；每行 = pastel 圆形缩略图（38pt）+ 名称（13pt/700）+ 彩色状态小字（逾期红 / 临期桃 / 闲置灰）；去掉「去处理」按钮，整行可点进详情。右侧灰色辅助位规范化为「具体日期」——左侧写状态+天数、右侧写日期（09-14 到期 / 06-01 登记），互不重复。无提醒时显示「一切妥当 ✅」空态。

三、全 APP 统一交互规范（正常 App 的「正常」就在这里）

📍 导航与返回

① Tab 页无返回键，二级页左上必返回；② 安卓物理返回 = iOS 右滑返回 = 左上返回，三者行为一致；③ 模态表单下滑关闭前检查未保存改动；④ 页面跳转只 push，禁止「套娃」超过 3 层，超过则用模态或 Tab 引导。

👆 触控与热区

① 可点击元素最小热区 44×44pt；② 主操作放拇指热区（底部 1/3）；③ 列表整行可点，不是只有文字可点；④ 点击后有按压态反馈（缩放/变暗），100ms 内响应。

💬 反馈与状态

① 每个列表都有四态：加载骨架屏 / 空状态 / 正常 / 网络错误重试；② 成功操作轻 Toast，破坏性操作必须二次确认；③ 提交按钮防重复点击（loading 态禁用）；④ 表单错误就地提示，不用弹窗。

⌨️ 键盘与表单

① 键盘弹起时把正在编辑的字段滚到可见区（底部按钮贴键盘）；② 数字字段调数字键盘；③ 「下一步」键按表单顺序跳字段；④ 保存中按钮转圈，成功后返回并刷新来源列表。

🌗 视觉一致性

① 圆角、间距、字号全 app 一套 token，不允许页面各写各的；② 普通信息背景板统一 40pt 标准行高（列表 cell、表单字段、概览小卡、快捷入口全app一致），仅特殊信息（备注多行、照片区、提醒条）允许放大——背景板大小差异过大画面会失衡；③ 主色只用于「可点击/当前态」，正文永远高对比；④ 弹层规范：选择器贴底上滑、确认弹窗居中；⑤ 深色模式作为 token 层实现，不单独画稿。

🔄 数据流转

① 从列表进详情改了数据 → 返回列表原地刷新该项不整页重载；② 删除后列表滑出动画 + Toast 带「撤销」；③ 搜索历史/筛选偏好本地持久化；④ 下拉刷新是列表页标配。
